# Documentación del análisis semántico

Esta carpeta conserva la especificación, matriz, decisiones y material de la
entrega semántica de Compiscript. Los documentos de defensa describen la
arquitectura exacta presentada y deben leerse junto con la etiqueta Git
`entrega-semantica-100`.

La rama actual continúa únicamente con Compiscript. Su arquitectura vigente se
describe en [ARQUITECTURA.md](ARQUITECTURA.md) y las instrucciones de ejecución
están en el [README principal](../../README.md).

## Documentos principales

| Documento | Propósito |
|---|---|
| [ARQUITECTURA.md](ARQUITECTURA.md) | Flujo técnico vigente de Compiscript. |
| [MATRIZ_CUMPLIMIENTO.md](MATRIZ_CUMPLIMIENTO.md) | Requisitos semánticos y evidencia. |
| [REGLAS_Y_DECISIONES.md](REGLAS_Y_DECISIONES.md) | Decisiones adoptadas durante la entrega. |
| [GUIA_COMPLETA_ENTREGA_Y_DEFENSA.md](GUIA_COMPLETA_ENTREGA_Y_DEFENSA.md) | Registro histórico de la presentación. |
| [GUIA_DEFENSA_POR_INTEGRANTE.md](GUIA_DEFENSA_POR_INTEGRANTE.md) | Distribución histórica del trabajo. |
| [GUIA_PRUEBAS_PRESENTACION.md](GUIA_PRUEBAS_PRESENTACION.md) | Pruebas ejecutadas durante la entrega. |

Las referencias de esos documentos a componentes que ya no están en la rama
actual permanecen como evidencia histórica y siguen siendo reproducibles desde
la etiqueta de la entrega.
